# Криптографические алгоритмы и защищённый мессенджер на Rust

Учебный проект, в котором криптографические примитивы реализованы вручную, покрыты тестами и затем использованы в клиент-серверном приложении.

## Что внутри

- блочные шифры AES (Rijndael), Twofish и LOKI97;
- RSA: генерация ключей, шифрование и учебные атаки;
- общий интерфейс симметричного шифра, примеры и Criterion-бенчмарки;
- обмен ключами Diffie–Hellman;
- двунаправленный gRPC-stream между сервером и GUI-клиентом;
- комнаты, зашифрованные сообщения и передача файлов;
- локальная история сообщений в SQLite.

Криптографические crates находятся в корне репозитория. Приложение мессенджера — отдельный Cargo workspace в [`messenger/`](messenger/): сервер построен на Tokio/Tonic, GUI — на egui/eframe.

```bash
# Криптографические библиотеки
cargo test --workspace

# Мессенджер
cd messenger
cargo run -p server
cargo run -p gui_client
```

Стек: Rust, Cargo, Tokio, Tonic/gRPC, Protocol Buffers, egui, SQLite.

Проект учебный: собственные реализации криптографии не проходили аудит и не предназначены для защиты реальных данных.
